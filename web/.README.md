# 🛕 DevGatha Quiz

हिंदी में धार्मिक सामान्य ज्ञान का ऑफलाइन क्विज़ ऐप।

## सुविधाएँ

- हिंदी में बहुविकल्पीय सवाल
- हर सवाल में चार विकल्प
- सही और गलत जवाब की जानकारी
- अंतिम स्कोर
- सर्वश्रेष्ठ स्कोर मोबाइल में सेव
- इंटरनेट के बिना क्विज़ खेलने की सुविधा

## तकनीक

- HTML
- CSS
- JavaScript
- Capacitor
- Android SDK
- Gradle
- GitHub Actions

## APK कैसे मिलेगी?

GitHub repository में Actions टैब खोलें।
Build सफल होने पर संबंधित workflow खोलें।
Artifacts सेक्शन से DevGatha-Quiz-APK डाउनलोड करें।
